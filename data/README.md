 # GeoAI-based Flood Resilience Assessment through Street Network

This project develops a GeoAI-supported workflow to assess flood risk and intervention impacts at the street-segment level in Gothenburg.

## Research Goal
To evaluate how flood scenarios affect street-network accessibility, population mobility, and essential service access.

## Workflow
1. Spatial data preprocessing in QGIS
2. HEV-based indicator construction
3. Risk index calculation
4. Random Forest classification for intervention recommendation
5. Result visualization

## Methods
- GIS spatial overlay
- Network accessibility analysis
- Multi-criteria decision-making
- Random Forest classification
- Feature importance analysis
